Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy carries its official name, description and grade, an original guide that cites its sources, a kind and a roadmap stage; missable trophies are flagged with save advice, a five-stage roadmap leads to the platinum, and a spoiler setting hides story trophies until they are earned. Progress is a checklist saved in the browser, with export and import, search, and filters by kind, grade and status — and the whole app is static files that work with the network off.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or serve app/ with any static server
```
